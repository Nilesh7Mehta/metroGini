GALLABOX SEND API (same for ALL outbound templates)
--------------------------------------------------------------------------------
Method:  POST
URL:     https://server.gallabox.com/devapi/messages/whatsapp

Headers:
  apiKey:      <from Gallabox Developer → API Keys>
  apiSecret:   <from Gallabox Developer → API Keys>
  Content-Type: application/json

Common body fields (always):
  channelId:   <Metrogini WhatsApp Channel ID>
  channelType: "whatsapp"
  recipient:   { "name": "<customer name>", "phone": "91XXXXXXXXXX" }

whatsapp.template changes per message:
  templateName + bodyValues

Tested: YES (Postman/curl + Gallabox UI) — credentials/channel OK

    "channelId": "YOUR_CHANNEL_ID",
