RULES
  Week:            Monday → next Monday (8 days)
  Order date:      ready_for_delivery_at (IST)
  Eligible status: ready_for_delivery | out_for_delivery | delivered
                   + vendor_revenue IS NOT NULL
  Grain:           vendor × pincode_group (zone) × week
  GST:             gst = ROUND(gross * 0.18); payable = gross + gst
  Status:
    today <= week_end  →  invoice_not_generated  (cannot pay)
    today >  week_end  →  pending                (invoice auto PDF)
    after pay          →  paid

Invoice PDF URL (either works):
  {{API_BASE_URL}}/uploads/vendor-payout-invoices/auto-vpb-1.pdf
  {{API_BASE_URL}}/api/uploads/vendor-payout-invoices/auto-vpb-1.pdf

2) PENDING PAYMENT
--------------------------------------------------------------------------------
GET /api/admin/vendor-payout/pending

Optional query:
  - pincode_group_id
  - search
  - week_start   (YYYY-MM-DD)

payment_status values:
  - pending                → week closed; invoice auto-generated; Send Payment enabled (listed FIRST)
  - invoice_not_generated  → week still running; listed LAST; NO pay button

tickers: one entry per closed unpaid week range
  e.g. "Payment pending for 13 Jul 2026 - 20 Jul 2026"

4) SEND PAYMENT
--------------------------------------------------------------------------------
POST /api/admin/vendor-payout/:batchId/pay

Example:
POST /api/admin/vendor-payout/vpb-1/pay

Content-Type: application/json

Body (only these two fields):
{
  "transaction_id": "TXN123456",
  "date": "2026-07-21"
}

Only allowed when payment_status = pending (week closed).
Invoice is auto-generated — no file upload.

Success response (200):
