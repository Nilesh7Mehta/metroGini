DELIVERY DATE AUTO-RESCHEDULE
=============================

Cron: src/cron/deliveryRescheduleCron.js
Schedule: 00:05 Asia/Kolkata daily
Migration: migrations/035_orders_delivery_reschedule.sql

When an order is still unfinished after its delivery_date, the cron bumps
only delivery_date to the assigned laundry's next work-shift day so all
existing delivery_date-based flows (task board, overdue, dashboards) keep working.

Eligibility
-----------
- vendor_id IS NOT NULL
- vendor_received_at IS NOT NULL
- delivery_date < today (APP_TIMEZONE)
- status IN ('in_process', 'order_finalized')

Update
------
- previous_delivery_date = old delivery_date
- delivery_date          = next work day from laundry_group_shift_schedule
- is_rescheduled         = true
- rescheduled_at         = NOW()

Does not change delivery_slot_id, status, or vendor_id.

Helper
------
getNextWorkDateAfter(laundryId, afterDate)
  → src/services/common/laundryGroupShiftSchedule.service.js

Vendor is notified in-app: "Delivery date rescheduled".
