ORDER LIFECYCLE (scenario order)
--------------------------------------------------------------------------------

1) AFTER BOOKING CONFIRMED (advance paid / order booked)
   Template:  booking_wash_by_kilo
   Trigger:   Razorpay advance webhook OR dummy/checkout booking success
   Vars:      {{1}} name | {{2}} ORD-xxx | {{3}} pickup date | {{4}} delivery date


2) MORNING OF PICKUP DAY (order still booked → out_for_pickup)
   Template:  pickup_day_reminder
   Trigger:   pickupCron (pickup_date = today)
   Vars:      {{1}} name | {{2}} ORD-xxx


3) AFTER RIDER ASSIGNED / PICKUP OTP TO SHARE
   Template:  order_pickup_update
   Trigger:   (1) Pickup morning cron IF rider already assigned
              (2) Fallback: rider starts pickup (startPickup) if missed
   Once:      once per order (deduped via "Order Pickup Update" notification)
   Vars:      {{1}} pickup OTP
   NOTE:      Not sent on orderSplit (rider assignment cron)


4) AFTER RIDER COMPLETES PICKUP (pickup OTP verified → picked_up)
   Template:  pickup_completed
   Trigger:   Rider verify pickup OTP
   Vars:      none


5) AFTER VENDOR FINALIZES WEIGHT / BILL (order_finalized)
   Template:  order_bill_payment_clone
   Trigger:   Vendor finalize order (remaining_amount > 0)
   Vars:      {{1}} weight kg | {{2}} total bill | {{3}} coupon | {{4}} amount payable
   Button:    Pay Now → Dynamic https://api.metrogini.com/api/pay/{{1}}
              ({{1}} = opaque pay_token, NOT numeric order id)


6) PAYMENT REMINDER (still unpaid before delivery)
   Template:  payment_reminder_clone
   Trigger:   (a) Hourly cron on delivery_date if unpaid
              (b) Vendor mark ready_for_delivery if unpaid
   Once:      once per order (deduped)
   Vars:      {{1}} ORD-xxx | {{2}} amount payable
   Button:    Pay Now → Dynamic https://api.metrogini.com/api/pay/{{1}}
              ({{1}} = opaque pay_token, NOT numeric order id)


7) AFTER ORDER OUT FOR DELIVERY (rider picks up from vendor)
   Template:  order_on_the_way
   Trigger:   Rider pickupFromVendor → out_for_delivery
   Vars:      {{1}} ORD-xxx | {{2}} delivery OTP


8) AFTER REMAINING / FULL PAYMENT RECEIVED
   Template:  payment_received
   Trigger:   Razorpay webhook payment.captured (remaining/full — not advance)
   Vars:      {{1}} ORD-xxx


9) AFTER ORDER DELIVERED (delivery OTP verified → delivered)
   Template:  order_delivered
   Trigger:   Rider verify delivery OTP
   Vars:      {{1}} ORD-xxx


10) ONE-TIME CUSTOMER, NO REPEAT ORDER (reengagement)
   Template:  customer_reengagement_offer
   Trigger:   Daily cron 10:00 IST
   Audience:  exactly 1 delivered order
   When:      21 days / 45 days / 90 days since that order (each once)
   Vars:      {{1}} name | {{2}} VALUED10


================================================================================
PAY LINK (not a template — used by Pay Now buttons)
================================================================================
URL:      GET /api/pay/:token   (opaque pay_token; numeric order ids rejected)
Action:   Creates/reuses Razorpay Payment Link for remaining_amount → redirect
Used by:  order_bill_payment_clone, payment_reminder_clone

QUICK LOOKUP
================================================================================
booking_wash_by_kilo          → after booking confirmed
pickup_day_reminder           → morning of pickup day
order_pickup_update           → pickup morning if rider assigned; else startPickup fallback
pickup_completed              → after pickup OTP success
order_bill_payment_clone      → after vendor finalize (bill + pay link)
payment_reminder_clone        → unpaid, before/on delivery day (once)
order_on_the_way              → rider picks up from vendor → out_for_delivery
payment_received              → after remaining payment success
order_delivered               → after delivery OTP success
customer_reengagement_offer   → one-time customer @ 21 / 45 / 90 days
